# Scope 管理

工程文档文件名使用下表的英文单词列。新增业务域时必须同时登记三种名称，禁止为已有业务域另造同义词。

| 2 字中文 | 4 字中文 | 英文单词 | 说明 |
| --- | --- | --- | --- |
| 架构 | 架构边界 | `architecture` | 运行时分层、接入通道、基础设施装配与部署边界 |
| 项目 | 项目管理 | `project` | 项目标识、路径匹配与项目缓存 |
| 约束 | 约束传递 | `pin` | Pin 跨项目约束推送与消费 |
| 百科 | 代码百科 | `repowiki` | RepoWiki 生成、版本、Webhook 与读取通道 |
| 记忆 | 决策记忆 | `memory` | 尚待实现的长期决策记忆 |
| 空间 | 工作空间 | `workspace` | Project 之上的组织边界；单用户用来拆分生活/工作 |
| 预览 | 页面预览 | `preview` | Preview 工作台、Pages 路径式页面、LPW 文档格式与专用组件渲染 |
| 问答 | 实时问答 | `qa` | Agent 与用户的富交互问答通道 |
